# Fathom

Fathom is a bioluminescent deep-sea maze chase for the browser. Graze plankton, map the trench with sonar, hide with ink, and evade predators that hunt by different senses.

## Run

```sh
npm ci
npm run dev
```

Build with `npm run build`; deploy `dist/`. Checks: `npm test`, `npm run typecheck`, `npm run lint`, and `npm run format`.

## Controls

- Move: arrows or WASD
- Sonar: Space
- Ink: Shift
- Confirm: Enter or Space
- Pause/back: Escape (or P)
- Mute: M
